# Beni Digital

App móvil del Gobierno Autónomo Departamental del Beni: los trámites de **Jichi**
(SEDAG), **Paititi** y **Sedede** en un solo lugar.

> **Prototipo**: login con cualquier contraseña y datos de ejemplo. No se conecta a ningún sistema.

## Probarla

```sh
export PATH=$HOME/development/flutter/bin:$PATH

flutter run -d chrome          # en el navegador (Ctrl+Shift+M para verla como celular)
flutter run                    # en un celular Android conectado por USB (necesita Java/Android Studio)
```
